# From desktop pilot to a commercial service

## Phase 1: supervised customer pilot

Use the installer on a normal Windows account, enter verified project data, configure providers and test real bilingual calls. Review qualification accuracy, response times, handoffs, report scope and delivery. Start with a small consented list. Measure actual provider spend and outcomes before setting prices.

Keep the existing computer running and use the included local storage initially. This avoids adding hosting costs before the workflow is validated. It does not provide unattended service when that computer is offline.

## Phase 2: dependable managed deployment

- Host a stable callback endpoint and call/report workers independent of a desktop session.
- Use a durable job queue and provider reconciliation for uncertain calls and messages.
- Add monitoring, actionable failure alerts, encrypted off-device backups and restore drills.
- Sign installers and updates; stage updates to a pilot machine before general rollout.
- Define support ownership, retention settings and incident response procedures.
- Use a commercial map tile plan if usage exceeds the public service's policy or operational needs.

## Phase 3: multi-customer product

- Authenticated users, organizations, enforced roles and tenant-isolated records.
- Relational project, customer, attempt, appointment and inventory tables with audited transitions.
- Server-side concurrency/capacity controls and project-scoped real-time events.
- Subscription/licensing, quotas, usage metering and billing reconciliation.
- Customer onboarding, support tooling and tested migration/update paths.

Do not claim “never fails.” Publish measured availability, provide recovery paths and separate a provider outage from a software defect. Provider fallback should be added only after testing voice quality, data transfer and costs; changing an API endpoint alone is insufficient.

## Business validation

Sell an outcome that can be measured: faster first response, complete lead records, reliable RM follow-up and visibility into site visits. Validate these with pilot customers; no conversion improvement or cost saving has been established by the automated tests. Choose licensing and review the Glitch name's availability separately before commercial launch.
